# expo-ai-starter

> Expo / React Native starter with streaming AI chat, voice input, secure backend proxy and App Store-ready defaults.

**Status:** 🚧 Early stage — design and roadmap published, implementation in progress. Stars, issues and ideas welcome.

## Why

Mobile AI apps often ship API keys in the binary and get rejected by App Store review for avoidable reasons.

## Planned features

- [ ] Streaming chat UI
- [ ] Voice input with speech-to-text
- [ ] Backend proxy so model keys never ship in the app
- [ ] Local caching of conversations
- [ ] App Store review checklist baked in (privacy manifest, account deletion, AI disclosure)
- [ ] EAS build and submit config

## Intended usage

```
npx create-expo-app my-app --template expo-ai-starter
```

_The interface above is the target design and may change._
